# Mapeo de inundaciones con Sentinel-1 y U-Net

**Examen parcial 2026-II — Pregunta 2**  
**Estado:** estructura inicial del proyecto; todavía no incluye entrenamiento ni código de inferencia.

## Objetivo

Implementar una U-Net **propia en PyTorch** para segmentación de agua a partir de imágenes SAR Sentinel-1 con bandas VV y VH. Comparar etiquetas doradas y débiles y evaluar la generalización en Lima (marzo de 2017) con referencia Copernicus EMSN038, o justificar Bolivia como respaldo si Lima no es viable.

## Estructura mínima

```text
sentinel1-flood-unet/
├── README.md
├── requirements.txt
├── .gitignore
├── configs/
│   └── experimentos.md
├── notebooks/
│   └── .gitkeep
├── src/

└── reports/
    └── .gitkeep
```

El archivo `.gitkeep` únicamente conserva una carpeta vacía en Git; puede retirarse cuando se añadan archivos reales.

## Qué va en cada lugar

- `configs/`: registro de decisiones comunes y los cuatro experimentos M1–M4. Más adelante contendrá las configuraciones que leerá el entrenamiento.
- `notebooks/`: notebook de exploración y, si hace falta, notebook de inspección de Lima. En Colab se pueden abrir desde GitHub.
- `src/`: implementación original de dataset, U-Net, entrenamiento, evaluación y herramientas geográficas; no se han creado scripts vacíos innecesarios.
- `data/`: caché y datos de trabajo locales **excluidos de GitHub**; consultar `data/README.md`.
- `outputs/`: checkpoints y resultados pesados **excluidos de GitHub**; consultar `outputs/README.md`.
- `reports/`: informe en formato NeurIPS y figuras pequeñas seleccionadas para el informe.

## Datos externos (no descargar todo de entrada)

- Sen1Floods11: https://github.com/cloudtostreet/Sen1Floods11
- Carpeta del bucket: `gs://sen1floods11/v1.1/`
- Sentinel-1 GRD de Lima: https://search.asf.alaska.edu/ o https://browser.dataspace.copernicus.eu/
- Cartografía EMSN038: https://mapping.emergency.copernicus.eu/activations/EMSN038/

La preparación debe verificar valores `-1` (ignorar), `0` (no agua), `1` (agua), el orden de VV/VH y la alineación geográfica de Lima. No se deben tratar automáticamente las delineaciones de inundación EMS como equivalentes a etiquetas de agua/no agua.

"""Compara modelos U-Net ya entrenados contra test (90) y Bolivia (15).

Reconoce automáticamente ejecuciones gold M1/M2 y weak M3/M4.

Ejemplos (desde la raiz del proyecto):
    python -m src.compare_bolivia --root data/raw/sen1floods11 \
        --run outputs/experimentos_gold/run_20261029_013146_547224
    python -m src.compare_bolivia --root data/raw/sen1floods11 \
        --run outputs/experimentos_weak/run_20261029_035455_467350

No vuelve a entrenar ni modifica los checkpoints.
"""
import argparse
import csv
import json
import subprocess
import sys
from pathlib import Path

import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt


GRUPOS = {
    'gold': ('M1_BCE', 'M2_BCE_Dice'),
    'weak': ('M3_Weak_BCE', 'M4_Weak_BCE_Dice'),
}


def detectar_modelos(run: Path, parser: argparse.ArgumentParser, grupo: str):
    if not run.is_dir():
        parser.error(f'No existe la carpeta de ejecucion: {run}')

    if grupo != 'auto':
        nombres = GRUPOS[grupo]
    else:
        grupos_completos = [nombres for nombres in GRUPOS.values()
                            if all((run / nombre / 'best.pt').is_file() for nombre in nombres)]
        if len(grupos_completos) == 1:
            nombres = grupos_completos[0]
        elif len(grupos_completos) > 1:
            parser.error('La carpeta contiene ambos grupos. Usa --grupo gold o --grupo weak.')
        else:
            encontrados = [str(p.relative_to(run)) for p in run.glob('*/best.pt')]
            parser.error('No se encontro un par completo de checkpoints M1/M2 o M3/M4.\n'
                         f'Checkpoints encontrados: {encontrados or "ninguno"}.\n'
                         'Comprueba que el entrenamiento terminara y exista best.pt en cada modelo.')

    for nombre in nombres:
        checkpoint = run / nombre / 'best.pt'
        if not checkpoint.is_file():
            parser.error(f'No se encuentra: {checkpoint}')
    return nombres


def main():
    p = argparse.ArgumentParser(description='Evaluacion geografica test vs Bolivia para M1/M2 o M3/M4')
    p.add_argument('--run', type=Path, required=True, help='Carpeta run_... con subcarpetas de modelos')
    p.add_argument('--root', type=Path, default=Path('data/raw/sen1floods11'))
    p.add_argument('--crop-size', type=int, default=512)
    p.add_argument('--batch-size', type=int, default=1)
    p.add_argument('--grupo', choices=['auto', 'gold', 'weak'], default='auto')
    args = p.parse_args()

    nombres = detectar_modelos(args.run, p, args.grupo)
    print('Modelos detectados:', ', '.join(nombres), flush=True)
    rows = []

    for nombre in nombres:
        checkpoint = args.run / nombre / 'best.pt'
        resultados = {}
        for split in ('test', 'bolivia'):
            out = args.run / nombre / split
            command = [
                sys.executable, '-m', 'src.test',
                '--root', str(args.root),
                '--checkpoint', str(checkpoint),
                '--split', split,
                '--limit', '0',
                '--crop-size', str(args.crop_size),
                '--batch-size', str(args.batch_size),
                '--output-dir', str(out),
            ]
            print(f'\nEVALUANDO {nombre} | {split.upper()}', flush=True)
            subprocess.run(command, check=True)
            metrics_path = out / f'metricas_{split}.json'
            resultados[split] = json.loads(metrics_path.read_text(encoding='utf-8'))

        test = resultados['test']
        bolivia = resultados['bolivia']
        rows.append({
            'modelo': nombre,
            'iou_test': test['iou_global'],
            'iou_bolivia': bolivia['iou_global'],
            'brecha_iou_test_menos_bolivia': test['iou_global'] - bolivia['iou_global'],
            'f1_test': test['f1_agua'],
            'f1_bolivia': bolivia['f1_agua'],
            'precision_bolivia': bolivia['precision_agua'],
            'recall_bolivia': bolivia['recall_agua'],
            'chips_test': test['chips'],
            'chips_bolivia': bolivia['chips'],
        })

    path = args.run / 'comparacion_geografica.csv'
    with path.open('w', encoding='utf-8', newline='') as f:
        writer = csv.DictWriter(f, fieldnames=list(rows[0]))
        writer.writeheader()
        writer.writerows(rows)

    width = 0.36
    xs = list(range(len(rows)))
    fig, ax = plt.subplots(figsize=(8, 5))
    ax.bar([x - width / 2 for x in xs], [r['iou_test'] for r in rows], width,
           label='Test interno (90)')
    ax.bar([x + width / 2 for x in xs], [r['iou_bolivia'] for r in rows], width,
           label='Bolivia (15)')
    ax.set_xticks(xs, [r['modelo'] for r in rows])
    ax.set_ylabel('IoU global (agua)')
    ax.set_ylim(0, 1)
    ax.set_title('Generalizacion geografica: Test vs Bolivia')
    ax.legend()
    ax.grid(axis='y', alpha=0.2)
    fig.tight_layout()
    figure = args.run / 'comparacion_geografica.png'
    fig.savefig(figure, dpi=150)
    plt.close(fig)

    print('\nRESULTADOS DE GENERALIZACION:')
    for row in rows:
        print(f"  {row['modelo']}: IoU test={row['iou_test']:.4f} | "
              f"IoU Bolivia={row['iou_bolivia']:.4f} | "
              f"Brecha test-Bolivia={row['brecha_iou_test_menos_bolivia']:+.4f}")
    print('Guardados:', path, 'y', figure)


if __name__ == '__main__':
    main()

# 3. Separar las categorías de inundación y río
categoria = flood["source"].fillna("").str.strip().str.lower()

inundacion = flood[categoria == "maximun height"].copy()
rios = flood[categoria == "river"].copy()

# 4. Seleccionar únicamente la cobertura WorldView-2

    footprints["SDP"] == "WorldView-2"

    geom_riverbank

"""Carga local de Sen1Floods11 v1.1 usando los splits oficiales.

Solo chips dorados para la primera prueba; -1 (NoData) se ignora.
"""
import csv
import random
from pathlib import Path

import numpy as np
import rasterio
from rasterio.windows import Window
import torch
from torch.utils.data import Dataset


class Sen1Floods11Dataset(Dataset):
    """Pares VV/VH y máscara manual; lectura por ventana, sin cargar todo a RAM."""

    def __init__(self, root, split="train", limit=None, crop_size=256, seed=42):
        self.root = Path(root)
        if split not in {"train", "valid", "test", "bolivia"}:
            raise ValueError("split debe ser train, valid, test o bolivia")
        self.split = split
        self.crop_size = crop_size
        self.random_crop = split == "train"
        self.random = random.Random(seed)

        base = self.root / "data/flood_events/HandLabeled"
        img_dir = base / "S1Hand"
        mask_dir = base / "LabelHand"
        csv_path = self.root / "splits/flood_handlabeled" / f"flood_{split}_data.csv"
        if not csv_path.is_file():
            raise FileNotFoundError(f"No existe el CSV del split: {csv_path}")
        if not img_dir.is_dir() or not mask_dir.is_dir():
            raise FileNotFoundError(f"Falta S1Hand o LabelHand dentro de {base}")

        # CSV oficial: ruta a imagen SAR, ruta a máscara; las rutas pueden ser largas.
        pairs = []
        missing = []
        with csv_path.open("r", encoding="utf-8-sig", newline="") as fh:
            for row in csv.reader(fh):
                if len(row) < 2:
                    continue
                img_name = row[0].strip().replace("\\", "/").split("/")[-1]
                mask_name = row[1].strip().replace("\\", "/").split("/")[-1]
                if not (img_name.endswith("_S1Hand.tif") and mask_name.endswith("_LabelHand.tif")):
                    # Permite una fila de cabecera, pero no mezcla capas incompatibles.
                    if "image" in img_name.lower() or "sar" in img_name.lower():
                        continue
                    raise ValueError(f"Columnas inesperadas en {csv_path}: {row[:2]}")
                if img_name.removesuffix("_S1Hand.tif") != mask_name.removesuffix("_LabelHand.tif"):
                    raise ValueError(f"Chip desparejado: {img_name} / {mask_name}")
                image = img_dir / img_name
                mask = mask_dir / mask_name
                if image.is_file() and mask.is_file():
                    pairs.append((image, mask))
                else:
                    missing.append((str(image), str(mask)))
        if missing:
            raise FileNotFoundError(
                f"Faltan {len(missing)} parejas del CSV {split}. Primera pareja: {missing[0]}"
            )
        if not pairs:
            raise ValueError(f"El CSV {csv_path} no tiene pares utilizables")

        self.random.shuffle(pairs)
        self.pairs = pairs if limit is None else pairs[:limit]
        if not self.pairs:
            raise ValueError("El límite debe ser mayor que cero")
        print(f"[{split}] {len(self.pairs)} imágenes seleccionadas de {len(pairs)}")

    def __len__(self):
        return len(self.pairs)

    def __getitem__(self, index):
        image_path, mask_path = self.pairs[index]
        with rasterio.open(image_path) as sar, rasterio.open(mask_path) as reference:
            if sar.count != 2 or reference.count != 1:
                raise ValueError(f"Bandas inesperadas en {image_path.name}")
            if (sar.width, sar.height) != (reference.width, reference.height):
                raise ValueError(f"Dimensiones distintas en {image_path.name}")
            # También verificamos la georreferenciación para no comparar grillas distintas.
            if sar.crs != reference.crs or not sar.transform.almost_equals(reference.transform):
                raise ValueError(f"Grillas geográficas distintas en {image_path.name}")

            size = self.crop_size
            if size is None:
                window = None  # Chip entero, normalmente 512 x 512.
            else:
                if size > min(sar.height, sar.width) or size <= 0:
                    raise ValueError(f"crop_size={size} no cabe en {image_path.name}")
                if self.random_crop:
                    r = random.randint(0, sar.height - size)
                    c = random.randint(0, sar.width - size)
                else:
                    r = (sar.height - size) // 2
                    c = (sar.width - size) // 2
                window = Window(c, r, size, size)

            image = sar.read([1, 2], window=window, masked=True)
            mask = reference.read(1, window=window, masked=True)

        x = image.astype(np.float32).filled(np.nan)
        y = mask.filled(-1).astype(np.int16)
        valid = np.isin(y, [0, 1]) & np.isfinite(x).all(axis=0)
        valid &= (x > -1000).all(axis=0)  # Descarta valores sentinel extremos.

        # Normalización inicial fija para VV y VH en dB; documentar su rango.
        x = np.nan_to_num(x, nan=-50.0, neginf=-50.0, posinf=5.0)
        x = (np.clip(x, -50.0, 5.0) + 50.0) / 55.0
        x[:, ~valid] = 0.0
        y = np.where(valid, y, 0).astype(np.float32)[None]
        valid = valid.astype(np.float32)[None]

        return (torch.from_numpy(x.copy()),
                torch.from_numpy(y.copy()),
                torch.from_numpy(valid.copy()))

def local_path(dest: Path, blob_name: str) -> Path:
    # Conservamos la estructura relativa a v1.1 dentro de data/raw/sen1floods11.
    prefix = f"{VERSION}/"
    if not blob_name.startswith(prefix):
        raise ValueError(f"Objeto fuera del prefijo esperado: {blob_name}")
    relative = blob_name[len(prefix):]
    if not relative or ".." in Path(relative).parts:
        raise ValueError(f"Ruta no segura: {blob_name}")
    return dest / Path(relative)


def md5_matches(path: Path, remote_md5: str | None) -> bool:
    if not remote_md5:
        return True
    digest = hashlib.md5()  # checksum de integridad del archivo; no se usa para seguridad
    with path.open("rb") as fh:
        for chunk in iter(lambda: fh.read(4 * 1024 * 1024), b""):
            digest.update(chunk)
    return digest.digest() == base64.b64decode(remote_md5)


def download_blob(blob, target: Path, verify_md5: bool) -> str:
    size = int(blob.size or 0)
    if target.is_file() and target.stat().st_size == size:
        if (not verify_md5) or md5_matches(target, blob.md5_hash):
            return "exists"

    target.parent.mkdir(parents=True, exist_ok=True)
    temp = target.with_name(target.name + ".part")
    last_error = None
    for attempt in range(1, 4):
        try:
            # .part evita dejar un GeoTIFF aparentemente completo si se interrumpe.
            if temp.exists():
                temp.unlink()
            blob.download_to_filename(str(temp), timeout=180, checksum="auto")
            if temp.stat().st_size != size:
                raise IOError(f"Tamaño incorrecto: {temp.stat().st_size} vs {size}")
            if verify_md5 and not md5_matches(temp, blob.md5_hash):
                raise IOError("Checksum MD5 distinto del origen")
            os.replace(temp, target)
            return "downloaded"
        except Exception as exc:
            last_error = exc
            if attempt < 3:
                time.sleep(2 * attempt)
    if temp.exists():
        temp.unlink()
    raise RuntimeError(f"No se descargó {blob.name}: {last_error}")


def download_metadata(dest: Path) -> str:
    dst = dest / "Sen1Floods11_Metadata.geojson"
    if dst.is_file() and dst.stat().st_size > 100:
        return "exists"
    dst.parent.mkdir(parents=True, exist_ok=True)
    tmp = dst.with_name(dst.name + ".part")
    try:
        with urlopen(META_URL, timeout=60) as resp, tmp.open("wb") as fh:
            while True:
                chunk = resp.read(1024 * 1024)
                if not chunk:
                    break
                fh.write(chunk)
        os.replace(tmp, dst)
    finally:
        if tmp.exists():
            tmp.unlink()
    return "downloaded"


def check_pair(dest: Path, image_layer: str, mask_layer: str, folder: str) -> None:
    base = dest / "data" / "flood_events" / folder
    image_dir, mask_dir = base / image_layer, base / mask_layer
    if not image_dir.is_dir() or not mask_dir.is_dir():
        print(f"  No se revisan pares {image_layer}/{mask_layer}: no están ambas carpetas")
        return
    # Nombre: EVENT_CHIPID_LAYER.tif. Se conserva el identificador completo.
    img_ids = {p.name[:-len(f'_{image_layer}.tif')] for p in image_dir.glob(f'*_{image_layer}.tif')}
    lab_ids = {p.name[:-len(f'_{mask_layer}.tif')] for p in mask_dir.glob(f'*_{mask_layer}.tif')}
    print(f"  {folder}: {image_layer}={len(img_ids)} | {mask_layer}={len(lab_ids)} | "
          f"parejas={len(img_ids & lab_ids)} | sin máscara={len(img_ids-lab_ids)} | "
          f"sin imagen={len(lab_ids-img_ids)}")
    if img_ids != lab_ids:
        print("  ATENCIÓN: revisa los archivos faltantes; el emparejamiento no está completo.")


def main():
    a = parse_args()
    if not 1 <= a.workers <= 16:
        sys.exit("--workers debe estar entre 1 y 16")

    categories = ["gold", "weak", "split"] if a.mode == "all" else [a.mode]
    prefixes = [f"{VERSION}/{p}" for cat in categories for p in GROUPS[cat]]
    if a.optical and a.mode in ("all", "gold"):
        prefixes.append(f"{VERSION}/{DATA}/HandLabeled/S2Hand/")

    client = storage.Client.create_anonymous_client()
    bucket = client.bucket(BUCKET)
    blobs = []
    print(f"Origen: gs://{BUCKET}/{VERSION}/")
    print("Consultando objetos del bucket público (todavía sin descargar)...", flush=True)
    try:
        for prefix in prefixes:
            found = [b for b in bucket.list_blobs(prefix=prefix)
                     if b.name.lower().endswith((".tif", ".tiff", ".csv"))]
            count_bytes = sum(int(b.size or 0) for b in found)
            print(f"  {prefix}: {len(found)} archivos; {count_bytes / (1024**3):.3f} GiB")
            if not found:
                print("  ADVERTENCIA: prefijo vacío; comprobar acceso o ruta.")
            blobs.extend(found)
    except Exception as exc:
        sys.exit(f"Error al listar bucket: {exc}. Verifica Internet y acceso público al bucket.")

    if not blobs or any(not any(b.name.startswith(p) for b in blobs) for p in prefixes):
        sys.exit("No se encontraron todos los grupos solicitados. No continuar con una descarga incompleta.")

    # Guardamos inventario local para que se pueda auditar la descarga.
    a.dest.mkdir(parents=True, exist_ok=True)
    manifest = [
        {"name": b.name, "size": int(b.size or 0), "md5_base64": b.md5_hash}
        for b in blobs
    ]
    print(f"TOTAL: {len(blobs)} archivos; {sum(x['size'] for x in manifest) / (1024**3):.2f} GiB")
    if a.dry_run:
        print("Modo de prueba: no se ha descargado ningún archivo.")
        return

    manifest_path = a.dest / "manifest_download.json"
    manifest_path.write_text(json.dumps(manifest, indent=2), encoding="utf-8")

                existing += state == "exists"

                failures += 1

    if failures:

    print("DESCARGA COMPLETA. Datos guardados en:", a.dest.resolve())

class WaterMetrics:
    """IoU global + media IoU por chip, F1, precisión, recall y confusión."""

    def __init__(self):
        self.tp = self.fp = self.tn = self.fn = 0
        self.chip_ious = []
        self.n_chips = 0
        self.n_valid = 0

    @torch.no_grad()
    def update(self, logits, labels, valid):
        p = torch.sigmoid(logits) >= 0.5
        y = labels >= 0.5
        v = valid > 0.5
        for i in range(p.shape[0]):
            pi, yi, vi = p[i], y[i], v[i]
            tp = int((pi & yi & vi).sum().item())
            fp = int((pi & ~yi & vi).sum().item())
            fn = int((~pi & yi & vi).sum().item())
            tn = int((~pi & ~yi & vi).sum().item())
            self.tp += tp
            self.fp += fp
            self.fn += fn
            self.tn += tn
            self.n_chips += 1
            self.n_valid += tp + fp + fn + tn
            if tp + fp + fn:
                self.chip_ious.append(tp / (tp + fp + fn))

    def summary(self):
        tp, fp, fn = self.tp, self.fp, self.fn
        return {
            "iou_global": tp / (tp + fp + fn) if tp + fp + fn else None,
            "iou_media_chips": (
                sum(self.chip_ious) / len(self.chip_ious) if self.chip_ious else None

            "chips": self.n_chips,
            "chips_iou_definido": len(self.chip_ious),
            "pixeles_validos": self.n_valid,
        }

"""Pérdida y métricas binarias: solo píxeles válidos (sin NoData)."""
import torch
from torch.nn import functional as F


def masked_bce(logits, labels, valid):
    loss_per_pixel = F.binary_cross_entropy_with_logits(
        logits, labels, reduction="none"
    )
    return (loss_per_pixel * valid).sum() / valid.sum().clamp_min(1.0)



def masked_dice(logits, labels, valid, smooth=1.0):
    """Soft Dice loss sobre agua (clase 1); ignora los pixeles NoData.

    Calcula Dice por chip y promedia solo los chips con pixeles validos.
    """
    probs = torch.sigmoid(logits) * valid
    targets = labels * valid
    dims = (1, 2, 3)
    intersection = (probs * targets).sum(dim=dims)
    denom = probs.sum(dim=dims) + targets.sum(dim=dims)
    dice_loss = 1.0 - (2.0 * intersection + smooth) / (denom + smooth)
    has_valid = valid.sum(dim=dims) > 0
    if not has_valid.any():
        return logits.sum() * 0.0
    return dice_loss[has_valid].mean()


def segmentation_loss(logits, labels, valid, name="bce"):
    """M1: BCE. M2: 0.5 * BCE + 0.5 * Soft Dice."""
    bce = masked_bce(logits, labels, valid)
    if name == "bce":
        return bce
    if name == "bce_dice":
        return 0.5 * bce + 0.5 * masked_dice(logits, labels, valid)
    raise ValueError(f"Funcion de perdida no admitida: {name}")

"""U-Net original: 2 canales SAR (VV/VH) -> 1 logit de agua por píxel."""
import torch
from torch import nn
from torch.nn import functional as F


class DoubleConv(nn.Module):
    """Convolución 3x3 -> BatchNorm -> ReLU (dos veces)."""

    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, padding=1, bias=False),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_channels, out_channels, 3, padding=1, bias=False),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
        )

    def forward(self, x):
        return self.layers(x)


class Down(nn.Module):
    """Reduce a la mitad la resolución espacial."""

    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.layers = nn.Sequential(
            nn.MaxPool2d(2), DoubleConv(in_channels, out_channels)
        )

    def forward(self, x):
        return self.layers(x)


class Up(nn.Module):
    """Interpola, concatena skip connection y procesa las características."""

    def __init__(self, in_channels, skip_channels, out_channels):
        super().__init__()
        self.conv = DoubleConv(in_channels + skip_channels, out_channels)

    def forward(self, x, skip):
        x = F.interpolate(x, size=skip.shape[-2:], mode="bilinear", align_corners=False)
        return self.conv(torch.cat((skip, x), dim=1))


class UNet(nn.Module):
    """Arquitectura encoder-decoder de 3 reducciones para prueba de entrenamiento."""

    def __init__(self, in_channels=2, out_channels=1, base=16):
        super().__init__()
        self.encoder0 = DoubleConv(in_channels, base)
        self.encoder1 = Down(base, base * 2)
        self.encoder2 = Down(base * 2, base * 4)
        self.encoder3 = Down(base * 4, base * 8)
        self.decoder1 = Up(base * 8, base * 4, base * 4)
        self.decoder2 = Up(base * 4, base * 2, base * 2)
        self.decoder3 = Up(base * 2, base, base)
        self.output = nn.Conv2d(base, out_channels, 1)

    def forward(self, x):
        a = self.encoder0(x)
        b = self.encoder1(a)
        c = self.encoder2(b)
        d = self.encoder3(c)
        x = self.decoder1(d, c)
        x = self.decoder2(x, b)
        x = self.decoder3(x, a)
        return self.output(x)  # Sin sigmoid; BCEWithLogitsLoss lo incorpora.

def contraste(banda):
    """Ajusta contraste solo para mostrar la imagen (no cambia el modelo)."""
    b = np.ma.asarray(banda).astype(np.float32).filled(np.nan)
    valores = b[np.isfinite(b) & (b > -1000)]
    if valores.size == 0:
        return np.zeros(b.shape, dtype=np.float32)
    bajo, alto = np.percentile(valores, [2, 98])
    return np.clip((np.nan_to_num(b, nan=bajo) - bajo) / max(alto - bajo, 1e-6), 0, 1)


class Evaluator:
    def __init__(self, model, device):
        self.model = model.to(device).eval()
        self.device = device

    @torch.no_grad()
    def evaluate(self, loader):
        metricas = WaterMetrics()
        for x, y, valid in loader:
            logits = self.model(x.to(self.device))
            metricas.update(logits, y.to(self.device), valid.to(self.device))
        return metricas.summary()

    @torch.no_grad()
    def save_example(self, dataset, filename, index):
        x, y, valid = dataset[index]
        logits = self.model(x.unsqueeze(0).to(self.device))
        pred = torch.sigmoid(logits)[0, 0].cpu().numpy() >= 0.5
        real = y[0].numpy() >= 0.5
        area = valid[0].numpy().astype(bool)
        image_path, _ = dataset.pairs[index]

        with rasterio.open(image_path) as src:
            vv, vh = src.read([1, 2], masked=True)
        if vv.shape != pred.shape:
            raise ValueError("Usa --crop-size 512 para comparar los chips originales completos.")

        # Busca RGB de Sentinel-2 en la misma ubicacion.
        s2_path = image_path.parent.parent / "S2Hand" / image_path.name.replace("_S1Hand.tif", "_S2Hand.tif")
        if s2_path.exists():
            with rasterio.open(s2_path) as src:
                rgb = src.read([4, 3, 2], masked=True)
            rgb_img = np.stack([contraste(b) for b in rgb], axis=-1)
            titulo_rgb = "Sentinel-2 RGB (optica)"
        else:
            rgb_img = None
            titulo_rgb = "Sentinel-2 no descargado"

        clases = ListedColormap(["#e5e7eb", "#0284c7", "#111827"])
        ref = np.where(area, real.astype(np.uint8), 2)
        salida = np.where(area, pred.astype(np.uint8), 2)
        errores = np.zeros(real.shape, dtype=np.uint8)
        errores[real & pred & area] = 1   # TP verde
        errores[~real & pred & area] = 2  # FP rojo
        errores[real & ~pred & area] = 3  # FN amarillo
        errores[~area] = 4               # NoData negro
        colores_error = ListedColormap(["#e5e7eb", "#16a34a", "#ef4444", "#facc15", "#111827"])

        tp = np.sum(real & pred & area)
        fp = np.sum(~real & pred & area)
        fn = np.sum(real & ~pred & area)
        iou = tp / (tp + fp + fn) if (tp + fp + fn) else None
        valor_iou = "n/d" if iou is None else f"{iou:.3f}"

        fig, axes = plt.subplots(2, 3, figsize=(15, 9))
        axes[0, 0].imshow(contraste(vv), cmap="gray")
        axes[0, 0].set_title("Sentinel-1 VV (radar)")
        axes[0, 1].imshow(contraste(vh), cmap="gray")
        axes[0, 1].set_title("Sentinel-1 VH (radar)")
        if rgb_img is not None:
            axes[0, 2].imshow(rgb_img)
        else:
            axes[0, 2].text(0.5, 0.5, "Sin imagen S2", ha="center", va="center", transform=axes[0, 2].transAxes)
        axes[0, 2].set_title(titulo_rgb)
        axes[1, 0].imshow(ref, cmap=clases, vmin=0, vmax=2)
        axes[1, 0].set_title("Referencia: agua azul")
        axes[1, 1].imshow(salida, cmap=clases, vmin=0, vmax=2)
        axes[1, 1].set_title("Prediccion U-Net: agua azul")
        axes[1, 2].imshow(errores, cmap=colores_error, vmin=0, vmax=4)
        axes[1, 2].set_title("TP verde | FP rojo | FN amarillo")
        for ax in axes.flat:
            ax.axis("off")
        fig.suptitle(f"{image_path.stem}   |   IoU del chip: {valor_iou}", fontsize=12)
        fig.tight_layout()
        filename = Path(filename)
        filename.parent.mkdir(parents=True, exist_ok=True)
        fig.savefig(filename, dpi=150, bbox_inches="tight")
        plt.close(fig)


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--root", type=Path, default=Path("data/raw/sen1floods11"))
    p.add_argument("--checkpoint", type=Path, default=Path("outputs/unet_prueba_best.pt"))
    p.add_argument("--split", choices=["valid", "test", "bolivia"], default="valid")
    p.add_argument("--limit", type=int, default=0, help="0 = todos los chips del split")
    p.add_argument("--batch-size", type=int, default=1)
    p.add_argument("--crop-size", type=int, default=512)
    p.add_argument("--output-dir", type=Path, default=Path("outputs"))
    args = p.parse_args()

    if args.split == "test":
        print("ATENCION: test es el conjunto reservado para evaluacion final.")
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    checkpoint = torch.load(args.checkpoint, map_location="cpu", weights_only=True)
    model = UNet(in_channels=2, out_channels=1, base=checkpoint["base"])
    model.load_state_dict(checkpoint["state_dict"])
    ds = Sen1Floods11Dataset(
        args.root, args.split, None if args.limit == 0 else args.limit,
        args.crop_size, checkpoint.get("seed", 42)
    )
    loader = DataLoader(ds, batch_size=args.batch_size, shuffle=False, num_workers=0)
    evaluator = Evaluator(model, device)
    stats = evaluator.evaluate(loader)
    args.output_dir.mkdir(parents=True, exist_ok=True)
    json_file = args.output_dir / f"metricas_{args.split}.json"
    json_file.write_text(json.dumps(stats, ensure_ascii=False, indent=2, allow_nan=False), encoding="utf-8")

    # Elegir dos imagenes de paises distintos, no siempre dataset[0].
    indices = []
    paises = set()
    for i, (ruta, _) in enumerate(ds.pairs):
        pais = ruta.stem.split("_", 1)[0]
        if pais not in paises:
            paises.add(pais)
            indices.append(i)
        if len(indices) == 2:
            break
    if len(indices) < 2 and len(ds) >= 2:
        indices = [0, 1]
    if len(indices) < 2:
        raise RuntimeError("El split seleccionado no contiene al menos dos chips para generar ejemplos.")

    for i in indices:
        chip = ds.pairs[i][0].stem.replace("_S1Hand", "")
        png = args.output_dir / f"prediccion_{args.split}_{chip}.png"
        evaluator.save_example(ds, png, i)
        print("Figura:", png)
    print(json.dumps(stats, ensure_ascii=False, indent=2))
    print("Metricas:", json_file)


if __name__ == "__main__":
    main()

def number(value):

class Trainer:
    def __init__(self, model, device, lr=1e-3):
        self.model = model.to(device)
        self.device = device
        self.optimizer = torch.optim.Adam(model.parameters(), lr=lr)

    def epoch(self, loader, training):
        self.model.train(training)
        stats = WaterMetrics()
        weighted_loss = 0.0
        valid_total = 0
        for x, y, valid in loader:
            x, y, valid = (t.to(self.device) for t in (x, y, valid))
            count = int(valid.sum().item())
            if count == 0:
                continue
            with torch.set_grad_enabled(training):
                logits = self.model(x)
                loss = masked_bce(logits, y, valid)
                if training:
                    self.optimizer.zero_grad(set_to_none=True)
                    loss.backward()

            weighted_loss += loss.item() * count
            valid_total += count
            stats.update(logits.detach(), y, valid)
        if not valid_total:
            raise RuntimeError("No se encontraron píxeles válidos para entrenar/evaluar")
        return {"loss": weighted_loss / valid_total, **stats.summary()}

    def fit(self, train_loader, valid_loader, epochs, output, base, crop_size, seed):

            )
            iou = va["iou_global"]
            if epoch == 1 or (iou is not None and iou > best_iou):

                    "normalizacion_db": [-50.0, 5.0],
                    "seed": seed,
                    "best_epoch": epoch,
                    "validation_metrics": va,
                }, output)
                print(f"  Mejor modelo guardado: {output}")

def json_dump(path, value):
    Path(path).write_text(json.dumps(value, indent=2, ensure_ascii=False, allow_nan=False), encoding="utf-8")


class WeakTrainer:
    def __init__(self, model, device, loss_name="bce", lr=3e-4, amp=False):
        self.model = model.to(device)
        self.device = device
        self.loss_name = loss_name
        self.optimizer = torch.optim.Adam(self.model.parameters(), lr=lr)
        self.amp_requested = bool(amp)
        if self.amp_requested and device.type == "cuda":
            capability = torch.cuda.get_device_capability()
            # En GPUs anteriores a Ampere, FP16 puede producir NaN durante el
            # entrenamiento de esta U-Net aunque la pérdida se calcule en FP32.
            self.amp = capability >= (8, 0)
            if not self.amp:
                print(
                    f"Aviso: AMP solicitado, pero la GPU tiene capacidad "
                    f"{capability[0]}.{capability[1]}; se usará FP32 para evitar NaN.",
                    flush=True,
                )
        else:
            self.amp = False
        self.scaler = torch.amp.GradScaler("cuda", enabled=self.amp)

    def run_epoch(self, loader, training):
        self.model.train(training)
        metricas = WaterMetrics() if not training else None
        total_loss = 0.0
        total_valid = 0
        for x, y, valid in loader:
            x = x.to(self.device, non_blocking=True)
            y = y.to(self.device, non_blocking=True)
            valid = valid.to(self.device, non_blocking=True)
            count = int(valid.sum().item())
            if count == 0:
                continue
            with torch.set_grad_enabled(training):
                with torch.amp.autocast(device_type="cuda", enabled=self.amp):
                    logits = self.model(x)
                    # Calcula la pérdida en FP32 aun con autocast para estabilidad.
                    loss = segmentation_loss(logits.float(), y, valid, self.loss_name)
                if training:
                    self.optimizer.zero_grad(set_to_none=True)
                    self.scaler.scale(loss).backward()
                    self.scaler.unscale_(self.optimizer)
                    torch.nn.utils.clip_grad_norm_(self.model.parameters(), 1.0)
                    self.scaler.step(self.optimizer)
                    self.scaler.update()
            total_loss += float(loss.detach().item()) * count
            total_valid += count
            if metricas is not None:
                metricas.update(logits.detach(), y, valid)
        if total_valid == 0:
            raise RuntimeError("No existen píxeles válidos")
        return {"loss": total_loss / total_valid,
                **(metricas.summary() if metricas is not None else {})}

    def fit(self, train_loader, valid_loader, sampler, args, counts):
        best_path = args.output
        best_path.parent.mkdir(parents=True, exist_ok=True)
        last_path = best_path.with_name("last.pt")
        history_path = best_path.with_suffix(".history.json")
        timing_path = best_path.with_suffix(".timing.json")
        history = []
        best_iou, best_epoch, first_epoch = -1.0, None, 1
        if args.resume:
            if last_path.exists():
                data = torch.load(last_path, map_location="cpu", weights_only=True)
                if (data.get("loss_name") != args.loss or
                    data.get("counts") != counts or
                    data.get("base") != args.base):
                    raise ValueError("Configuración distinta a la guardada en last.pt")
                self.model.load_state_dict(data["state_dict"])
                self.optimizer.load_state_dict(data["optimizer_state_dict"])
                if self.amp and data.get("scaler_state_dict"):
                    self.scaler.load_state_dict(data["scaler_state_dict"])
                first_epoch = data["epoch"] + 1
                best_iou, best_epoch = data["best_iou"], data["best_epoch"]
                history = json.loads(history_path.read_text(encoding="utf-8"))
                print(f"Reanudando desde época {first_epoch}; mejor IoU={best_iou:.4f}")
            else:
                print("No existe last.pt: se iniciará desde cero")
        start = time.perf_counter()
        epochs_done = 0
        for epoch in range(first_epoch, args.epochs + 1):
            sampler.set_epoch(epoch)
            t0 = time.perf_counter()
            tr = self.run_epoch(train_loader, True)
            if self.device.type == "cuda":
                torch.cuda.synchronize()
            t_train = time.perf_counter() - t0
            t1 = time.perf_counter()
            val = self.run_epoch(valid_loader, False)
            if self.device.type == "cuda":
                torch.cuda.synchronize()
            t_valid = time.perf_counter() - t1
            iou = val["iou_global"]
            improved = iou is not None and iou > best_iou
            if improved:
                best_iou, best_epoch = iou, epoch
                torch.save({
                    "state_dict": self.model.state_dict(), "base": args.base,
                    "crop_size_train": args.crop_size, "normalizacion_db": [-50.0, 5.0],
                    "seed": args.seed, "loss_name": args.loss, "best_epoch": epoch,
                    "validation_metrics": val, "training_counts": counts,
                    "model_family": "gold_weak", "gold_fraction": 0.5,
                }, best_path)
            history.append({
                "epoch": epoch, "train": tr, "valid": val,
                "tiempo_train_s": round(t_train, 2),
                "tiempo_valid_s": round(t_valid, 2),
                "tiempo_epoca_s": round(t_train + t_valid, 2),
            })
            json_dump(history_path, history)
            torch.save({
                "state_dict": self.model.state_dict(),
                "optimizer_state_dict": self.optimizer.state_dict(),
                "scaler_state_dict": self.scaler.state_dict(),
                "epoch": epoch, "best_iou": best_iou, "best_epoch": best_epoch,
                "loss_name": args.loss, "counts": counts, "base": args.base,
                "seed": args.seed, "crop_size": args.crop_size,
            }, last_path)
            epochs_done += 1
            print(f"Época {epoch}/{args.epochs} | Train={tr['loss']:.4f} | "
                  f"Valid={val['loss']:.4f} | IoU={iou:.4f} | "
                  f"F1={val['f1_agua']:.4f} | "
                  f"Train={t_train:.1f}s | Valid={t_valid:.1f}s "
                  f"{'[MEJOR]' if improved else ''}", flush=True)
            if args.patience > 0 and best_epoch is not None and epoch - best_epoch >= args.patience:
                print("Early stopping: sin mejora del IoU de validación", flush=True)
                break
        json_dump(timing_path, {
            "tiempo_sesion_s": round(time.perf_counter() - start, 2),
            "epocas_ejecutadas_en_sesion": epochs_done,
            "mejor_epoca": best_epoch, "mejor_iou_valid": best_iou,
            "tiempo_epocas_acumulado_s": round(sum(h["tiempo_epoca_s"] for h in history), 2),
            "cuentas": counts,
        })
        return history

"""Sen1Floods11: pares de etiquetas débiles S1Otsu, con auditoría espacial.

Misma normalización VV/VH que src.dataset.Sen1Floods11Dataset.
"""
import json
import math
import random
from pathlib import Path

import numpy as np
import rasterio
from rasterio.windows import Window
from rasterio.warp import transform_bounds
import torch
from torch.utils.data import Dataset, Sampler

def bounds_wgs84(path):
    with rasterio.open(path) as src:
        if src.crs is None:
            raise ValueError(f"GeoTIFF sin CRS: {path}")
        if src.crs.to_epsg() == 4326:
            return tuple(src.bounds)
        return transform_bounds(src.crs, "EPSG:4326", *src.bounds)


def overlap(a, b):
    """Solapamiento de área positivo de dos bounding boxes (sin incluir bordes)."""
    return min(a[2], b[2]) > max(a[0], b[0]) and min(a[3], b[3]) > max(a[1], b[1])


class Sen1WeakDataset(Dataset):
    """Chips S1Weak + S1OtsuLabelWeak, excluyendo regiones retenidas."""

    def __init__(self, root, crop_size=512, limit=None, seed=42, audit_path=None):
        self.root = Path(root)
        self.crop_size = crop_size
        self.rng = random.Random(seed)
        weak_root = self.root / "data/flood_events/WeaklyLabeled"
        image_dir = weak_root / "S1Weak"
        mask_dir = weak_root / "S1OtsuLabelWeak"
        if not image_dir.is_dir() or not mask_dir.is_dir():
            raise FileNotFoundError("Faltan S1Weak / S1OtsuLabelWeak. Descarga con --mode weak")

        # Recopilar regiones doradas reservadas: no usar en el entrenamiento.
        holdout = []
        for split in ("valid", "test", "bolivia"):
            ref = Sen1Floods11Dataset(self.root, split, limit=None, crop_size=crop_size, seed=seed)
            holdout += [(path.stem.split("_", 1)[0].casefold(), bounds_wgs84(path))
                        for path, _ in ref.pairs]

        images = sorted(image_dir.glob("*_S1Weak.tif"))
        if not images:
            raise FileNotFoundError(f"No hay chips S1Weak en {image_dir}")
        pairs, ignored = [], {"bolivia": 0, "solapamiento_holdout": 0}
        missing = []
        for image in images:
            prefix = image.name.removesuffix("_S1Weak.tif")
            mask = mask_dir / f"{prefix}_S1OtsuLabelWeak.tif"
            if not mask.is_file():
                missing.append(mask.name)
                continue
            country = prefix.split("_", 1)[0].casefold()
            if country == "bolivia":
                ignored["bolivia"] += 1
                continue
            bbox = bounds_wgs84(image)
            if any(overlap(bbox, ref_bbox) for ref_country, ref_bbox in holdout
                   if ref_country == country):
                ignored["solapamiento_holdout"] += 1
                continue
            pairs.append((image, mask))
        if missing:
            raise FileNotFoundError(
                f"Faltan {len(missing)} máscaras débiles. Primera: {missing[0]}"
            )
        if not pairs:
            raise ValueError("Tras excluir holdouts, no quedan chips débiles")
        self.rng.shuffle(pairs)
        allowed = len(pairs)
        self.pairs = pairs[:limit] if limit is not None else pairs
        summary = {
            "archivos_S1Weak": len(images), "pares_debiles_admisibles": allowed,
            "pares_usados": len(self.pairs), "exclusiones": ignored,
            "criterio": "Excluir Bolivia y bbox que intersecta valid/test/Bolivia",
            "fuente_etiqueta": "S1OtsuLabelWeak",
            "advertencia": "El filtrado espacial no garantiza independencia entre eventos cercanos",
        }
        if audit_path is not None:
            path = Path(audit_path)
            path.parent.mkdir(parents=True, exist_ok=True)
            path.write_text(json.dumps(summary, indent=2, ensure_ascii=False), encoding="utf-8")
        print(f"[weak] {len(self.pairs)} parejas seleccionadas de {len(images)} "
              f"(excluidas Bolivia={ignored['bolivia']}, overlap={ignored['solapamiento_holdout']})")

    def __len__(self):
        return len(self.pairs)

    def __getitem__(self, idx):
        image_path, mask_path = self.pairs[idx]
        with rasterio.open(image_path) as sar, rasterio.open(mask_path) as reference:
            if sar.count != 2 or reference.count != 1:
                raise ValueError(f"Bandas inesperadas: {image_path.name}")
            if (sar.height, sar.width) != (reference.height, reference.width):
                raise ValueError(f"Dimensiones distintas: {image_path.name}")
            if sar.crs != reference.crs or not sar.transform.almost_equals(reference.transform):
                raise ValueError(f"Grillas distintas: {image_path.name}")
            size = self.crop_size
            if size is None:
                window = None
            else:
                if size <= 0 or size > min(sar.height, sar.width):
                    raise ValueError(f"crop-size={size} no cabe en {image_path.name}")
                row = random.randint(0, sar.height - size)
                col = random.randint(0, sar.width - size)
                window = Window(col, row, size, size)
            image = sar.read([1, 2], window=window, masked=True)
            mask = reference.read(1, window=window, masked=True)
        x = image.astype(np.float32).filled(np.nan)
        y = mask.filled(-1).astype(np.int16)
        valid = np.isin(y, [0, 1]) & np.isfinite(x).all(axis=0)
        valid &= (x > -1000).all(axis=0)
        x = np.nan_to_num(x, nan=-50.0, neginf=-50.0, posinf=5.0)
        x = (np.clip(x, -50.0, 5.0) + 50.0) / 55.0
        x[:, ~valid] = 0.0
        y = np.where(valid, y, 0).astype(np.float32)[None]
        valid = valid.astype(np.float32)[None]
        return (torch.from_numpy(x.copy()),
                torch.from_numpy(y.copy()),
                torch.from_numpy(valid.copy()))


class BalancedGoldWeakBatchSampler(Sampler):
    """Una pasada por TODAS las imágenes débiles en cada época.

    Cada lote combina aprox. 50% doradas (con reemplazo) y 50% débiles.
    Por ello cada muestra débil se usa exactamente una vez por época;
    las doradas se repiten para no quedar ignoradas por el gran desbalance.
    """

    def __init__(self, gold_count, weak_count, batch_size=8, seed=42):
        if gold_count < 1 or weak_count < 1:
            raise ValueError("Se requieren muestras doradas y débiles")
        if batch_size < 2 or batch_size % 2:
            raise ValueError("batch-size debe ser PAR y >= 2")
        self.gold_count = gold_count
        self.weak_count = weak_count
        self.weak_per_batch = batch_size // 2
        self.seed = seed
        self.current_epoch = 0

    def set_epoch(self, epoch):
        self.current_epoch = epoch

    def __iter__(self):
        rng = random.Random(self.seed + self.current_epoch)
        weak_indices = list(range(self.gold_count, self.gold_count + self.weak_count))
        rng.shuffle(weak_indices)
        for pos in range(0, len(weak_indices), self.weak_per_batch):
            weak_batch = weak_indices[pos:pos + self.weak_per_batch]
            gold_batch = [rng.randrange(self.gold_count) for _ in weak_batch]
            batch = gold_batch + weak_batch
            rng.shuffle(batch)
            yield batch

    def __len__(self):
        return math.ceil(self.weak_count / self.weak_per_batch)
